Come installare (Android)

  1. Tocca il pulsante di download. Se il telefono o il browser avvisa che il file potrebbe essere dannoso, tocca «Scarica comunque» (oppure «Mantieni»).
  2. Apri il file scaricato (dalla notifica o dalla cartella Download).
  3. Se il telefono chiede di installare da fonti sconosciute, tocca «Impostazioni», consenti per questo browser e torna indietro.
